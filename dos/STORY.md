เขียนโปรแกรม DOS ในปี 2026

สมัยก่อนตอนยังใช้เครื่องมือเขียนโปรแกรมของ Borland (เช่น Turbo Pascal) เวลามีเวอร์ชันใหม่ออกมา เราก็ต้องเปิดดูเอกสารว่ามีอะไรใหม่บ้าง จะมีไฟล์ README แนบมากับโปรแกรมเล็กๆ ชื่อ README.COM ไว้อ่านเอกสารพวกนี้ เพราะมันยาวหลายหน้า

แต่พอเป็นเอกสารภาษาไทย การอ่านในยุคนั้นยุ่งกว่านั้นเยอะ ต้อง load โปรแกรมที่เรียกว่า Thai Driver ก่อน แล้วค่อยเรียก README ขึ้นมา แต่ก็ยังเจอปัญหาแสดงผลไม่ครบ 80 คอลัมน์ เพราะสระกับวรรณยุกต์ไทยมันถูกนับรวมเป็นตัวอักษรด้วย ไม่งั้นก็ต้องไปเปิดผ่าน Word Processor อย่าง RW หรือ CW แทน แต่ก็เสี่ยงเผลอไปแก้ข้อความในไฟล์โดยไม่ตั้งใจ

ตอนนั้นเคยคิดอยากทำโปรแกรมแบบ README ที่รองรับภาษาไทยด้วย ทำงานได้กับเครื่องไหนก็ได้ ไม่ต้องพึ่ง Thai Driver ไม่ต้องผูกกับระบบภาษาไทยของค่ายไหน แต่พอ Windows มา ความจำเป็นแบบนี้ก็ลดลงเรื่อยๆ เลยไม่ได้สานต่อ

จนมาถึงตอนนี้ ไปเปิดทดสอบซอฟต์แวร์เก่าๆ แล้วเจอเอกสารที่แนบมากับไฟล์ ความคิดเดิมก็กลับมาอีกครั้ง คราวนี้ไปเจอโปรแกรม TREAD ที่ทำแบบนี้ได้พอดี แต่ติดที่มันอ่านได้แค่รหัสภาษาไทยแบบสมอ. (TIS) เจอไฟล์รหัสเกษตร (KU) ต้องแปลงไฟล์ก่อนถึงจะเปิดได้ เลยลองเอาไปถาม ZCode ว่าพอจะมีวิธีทำให้มันอ่านรหัสเกษตรได้ไหม ปรากฏว่ามันไม่รู้จักรหัสเกษตรเลย เลยต้องสอนมันก่อน จนสุดท้ายมันแปลงโค้ด TREAD ให้อ่านไฟล์รหัสเกษตรได้สำเร็จ

TREAD เขียนด้วย Turbo C ใช้ BGI Graphics รองรับ Hercules/EGA/VGA ฟอนต์ขนาด 8x14 แสดงได้ 25 บรรทัดที่ความละเอียดเท่า EGA ขนาดโปรแกรมประมาณ 50K

ในเมื่อ ZCode มันเข้าใจการแปลงรหัสภาษาไทยแล้ว เลยลองให้มันเขียนขึ้นมาใหม่ทั้งหมดเป็นภาษา Assembly เพราะคิดว่าน่าจะเร็วที่สุด เลือกฟอนต์ 8x19 เพื่อให้ได้ 25 บรรทัดบน VGA แบบความละเอียดจริงๆ ส่วนโหมดจอแบบอื่นบรรทัดก็จะลดหลั่นกันไป ทำทั้งทีก็เลยรองรับลงไปถึง CGA เผื่อเอาไปใช้กับเครื่องเก่าๆ ได้ แม้จะเหลือแค่ 10 บรรทัดเพราะความละเอียดต่ำ (640x200) ก็ตาม โปรแกรมเขียนตัวอักษรลง memory ตรงๆ เพื่อให้เร็วที่สุด

ฟอนต์ไทยเอามาจากโปรแกรม AxThai เพราะชอบและอ่านง่าย แต่พอเป็นภาษาอังกฤษมันจะออกตัวหนา อ่านยาก เลยไปหาฟอนต์บางขนาด 8x19 เหมือนกัน ได้ฟอนต์ของ DOS-V มาใช้แทน ส่วนอักษรสัญลักษณ์พิเศษก็เทียบกับ CW แล้วแก้เพิ่มเอง งานแก้ฟอนต์ทำเองด้วยโปรแกรม Fontraption บน DOS

อีกอย่างที่ใส่ไปคือให้โปรแกรมแสดงผลตัวอักษรตามรหัสจัดรูปแบบแบบ WordStar ที่ไฟล์ CW/RW ใช้กันได้ด้วย ทั้งตัวหนา ตัวเอียง ตัวขยาย (กว้างเป็น 2 เท่า) ขีดเส้นใต้เดี่ยว/คู่ ตัวยก/ตัวห้อย เปิดไฟล์เอกสารเก่าๆ มาก็เห็นหน้าตาเหมือนตอนพิมพ์จริงในโปรแกรมนั้นๆ ไม่ใช่แค่ตัวหนังสือเปล่าๆ

ปรับกันอยู่หลายรอบกว่าจะทำงานได้ ระหว่างทางก็เจอ bug บ้าง ที่ Hercules บ้าง ที่ CGA บ้าง บาง bug ZCode ก็หาไม่เจอ หรือคิดนานมาก พอทำงานได้ระดับหนึ่งแล้ว ลองให้ ZCode ช่วยดูว่าทำให้เร็วขึ้นได้ไหม มันเสนอให้ย้าย memory ตอนเลื่อนหน้าจอแทนการวาดใหม่ทั้งหมด กับใส่ตาราง (แบบสูตรคูณ) แทนการคูณเลขตรงๆ ซึ่งกิน clock เยอะ ทำให้เร็วขึ้นจริง พร้อม benchmark เทียบให้ดูด้วย

หลัง optimize รอบแรก โปรแกรมทำงานดีขึ้นมาก แต่ไปเจอ bug การแสดงผลบน DOSBox ไม่กระทบการทำงานหลักเท่าไหร่ แต่ให้ ZCode ไล่หาก็หาไม่เจอ ใช้เวลานานมาก เลยให้ export โค้ดทั้งหมดออกมาแล้วเอาไปลองถาม Claude Code ดู

โจทย์ที่ให้ Claude Code คือทำให้เร็วสุด เล็กสุด พร้อมแจ้ง bug ที่เจอ Claude Code ใช้เทคนิค optimize instruction เพิ่มเติม ลบโค้ดที่ไม่ได้ใช้ทิ้ง แล้วบีบอัดไฟล์ฟอนต์ ทำให้ขนาดโปรแกรมลดลงครึ่งหนึ่ง (จาก 15K เหลือ 7K) แถมยังหา bug ที่หาไม่เจอมานานเจอจนแก้ได้ด้วย จนกลายมาเป็นโปรแกรม READ.COM ตัวนี้
